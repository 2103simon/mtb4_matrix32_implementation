# Offline scientific analysis

This package contains the cross-device analysis pipeline for tactile MCU
measurements, Matrix32 BLE commands, scope-recorded electrical pulses and
Nano synchronization evidence.

- `paths.py`: separate raw-recording inputs from derived results.
- `migrate_layout.py`: dry-run or lossless migration of existing analyses.
- `finalize_layout.py`: verified, reversible archival of old analysis outside raw.
- `audit_layout.py`: read-only integrity and Git-publication cleanup checks.
- `register_recording.py`: bind new clean recordings to external results.
- `analyze_frequency_transitions.py`, `analyze_stimulation_shutdown.py`,
  `analyze_command_timing.py`: three independent analyses.
- `run_extended_analysis.py`: all three analyses and the verified final report.
- `build_final_experiment_report.py`, `present_scientific_report.py`:
  the scientific and technical reports.
- `publish_reports.py`: small, Git-versionable reference snapshots.

Hardware-specific recording and pulse review components remain under
`oscilloscope/` for now. Old `oscilloscope.*` names for the moved scientific
modules remain thin backward-compatible wrappers.

Source recording: `data/recordings/<run_id>/`
Derived analysis: `results/<run_id>/analysis/`
Curated published report: `reports/<run_id>/<tag>/`

Recording and signed review files are never regenerated by migration or
publication. See [full guide](../docs/recording_results_separation.md).
